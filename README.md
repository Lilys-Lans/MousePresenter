# MousePresenter

Управление показом слайдов PowerPoint мышью. Маленькая программа на C# для Windows: живёт в трее, не требует Python и сторонних библиотек.

## Возможности

Пока на переднем плане идёт показ слайдов PowerPoint:

| Действие мыши | Результат |
| Правая кнопка | Следующий слайд |
| Левая кнопка | Предыдущий слайд |
| Колесо вверх / вниз | Громкость системы громче / тише |
| Нажатие на колесо | Выход из показа (как `Esc`), сам PowerPoint остаётся открытым |

Вне показа слайдов мышь работает как обычно.

## Особенности

- Работает только с окнами PowerPoint (`POWERPNT` и `PPTVIEW`), в других программах мышь не трогает.
- Отпускание кнопки тоже подавляется, поэтому по правому клику не появляется контекстное меню.
- Обработчик не тратит ресурсы на движение мыши.
- Нет консольного окна, только значок мышки в трее.
- Нельзя запустить второй экземпляр.

## Требования

- Windows 8.1 или новее
- .NET Framework 4 (уже входит в Windows 8.1 и новее)
- Python и другие зависимости не нужны

## Сборка

1. Скачайте или клонируйте репозиторий. В одной папке должны лежать три файла:
   - `MousePresenter.cs`
   - `build_MousePresenter.bat`
   - `mouse_presenter.ico`
2. Дважды щёлкните `build_MousePresenter.bat`. Он использует компилятор, который уже есть в Windows (.NET Framework 4), и через пару секунд рядом появится `MousePresenter.exe` с иконкой мышки.

## Использование

1. Запустите `MousePresenter.exe`. В трее появится значок мышки и всплывёт подсказка.
2. Откройте презентацию PowerPoint и начните показ слайдов.
3. Управляйте мышью, как описано в таблице выше.
4. Чтобы закрыть программу, нажмите правой кнопкой на значок в трее и выберите **Выход**.

## Антивирус и SmartScreen

Программа перехватывает мышь глобально (low-level hook), поэтому антивирус или SmartScreen могут ругаться на собранный exe. Исходный код открыт, вы можете прочитать его в `MousePresenter.cs` и собрать exe сами.

Если Windows блокирует запуск, нажмите **Подробнее → Выполнить в любом случае**.
